# Lexi

Lexi is a controlled language generation framework.

Its goal is to rewrite text while preserving meaning under configurable lexical constraints.

Examples include:

- Germanic-root English

Future language generation support inlcudes:

- Native Japanese vocabulary
- Native Korean vocabulary
- Persian with reduced Arabic loanwords

This project explores NLP, lexical constraints, and controllable LLM generation.


## Current Status

🚧 Early development

## Planned Features

- Rewrite text using configurable lexical constraints
- Support multiple languages
- Preserve meaning and grammar
- Evaluate lexical compliance
- Integrate with modern LLMs
